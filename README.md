DocuMind RAG is a local AI assistant for chatting with your PDFs.
Upload multiple documents, ask questions, and get answers grounded in the actual content — with page citations and source previews.

I built this project to understand RAG beyond high-level frameworks: from chunking and embeddings to retrieval, prompting, and local LLM generation.

Built with: FastAPI · Streamlit · Sentence Transformers · Ollama · Llama 3.2
